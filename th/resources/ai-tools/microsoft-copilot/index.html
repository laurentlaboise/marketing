Microsoft Copilot

Microsoft Copilot มีหลายชั้น แชทบนเว็บสำหรับผู้บริโภค Copilot ใน Windows และ Copilot ใน Microsoft 365 ที่เป็นส่วนเสริมงานแยกต่างหาก เมื่อใช้ชุดงานองค์กร Microsoft ระบุว่าอ้างอิงข้อมูลผ่าน Microsoft Graph ได้

Microsoft Copilot คืออะไร?

ชื่อ Copilot ใช้กับหลายผลิตภัณฑ์ ชั้นที่เปิดได้ทันทีคือแชทผู้บริโภคบน copilot.microsoft.com อีกชั้นคือ Copilot ที่มากับ Windows และอีกชั้นคือ Copilot ใน Microsoft 365 ซึ่งทำงานในเวิร์ด เอกเซล เพาเวอร์พอยต์ เอาท์ลุค และทีมส์ ตามที่ Microsoft อธิบาย ชั้นสุดท้ายเป็นส่วนเสริมงานที่คิดเงินแยก อย่าสมมติว่าบัญชีออฟฟิศที่ใช้อยู่มีครบทุกปุ่ม

เมื่อใช้ Copilot ใน Microsoft 365 ผู้ขายระบุว่าโมเดลอ้างอิงหรือกราวด์กับข้อมูลผ่าน Microsoft Graph ได้ในขอบเขตที่องค์กรอนุญาต นั่นทำให้สรุปประชุมหรือร่างจดหมายจากไฟล์ในเทแนนท์มีความหมายกว่าแชทเปล่า มันไม่ได้แปลว่าทุกประโยคถูกต้อง และไม่ได้แปลว่าไฟล์นอกสิทธิ์จะถูกดึงมาได้

ชั้นผู้บริโภคเป็นแบบฟรีเมียมตามที่ไดเรกทอรีบันทึก มีโหมดฟรีและโหมดที่คิดเงินเพิ่มตามรอบของ Microsoft เราไม่ใส่ราคา ตรวจหน้าแผนของบัญชีที่คุณจะใช้จริง เพราะสิทธิ์บนเว็บ บนวินโดวส์ และในชุด 365 ไม่ใช่ใบเดียวกัน

สำเนาภาษาไทยจากทุกชั้นยังต้องมีคนอ่าน โมเดลช่วยย่อสไลด์หรือจัดตารางได้เร็ว แต่คำเรียกตำแหน่ง คำราชาศัพท์ในงานรัฐ และชื่อสินค้าท้องถิ่นพลาดได้ อย่าวางสำเนาบัตรประชาชน สัญญา หรือรายชื่อผู้ป่วยลงแชทผู้บริโภคเด็ดขาด

ชั้นที่ Microsoft แยกไว้

  • Copilot บนเว็บสำหรับผู้บริโภคที่ copilot.microsoft.com
  • Copilot ใน Windows ตามที่ Microsoft ประกาศในระบบปฏิบัติการ
  • Copilot ใน Microsoft 365 สำหรับ Word, Excel, PowerPoint, Outlook และ Teams ซึ่งเป็นส่วนเสริมงานแยก
  • การอ้างอิงข้อมูลผ่าน Microsoft Graph เมื่อใช้ Copilot ในชุด 365 ตามที่ Microsoft ระบุ
  • ชั้นผู้บริโภคแบบฟรีเมียม — ตรวจสิทธิ์ปัจจุบันในบัญชีของคุณ

ชื่อแผนและขอบเขตกราวด์เปลี่ยนตามสัญญาองค์กร อย่าคัดลอกตารางราคาจากบทความภายนอกมาใส่ใบเสนอ

เหมาะกับทีมแบบไหน

  • เอสเอ็มอีที่นั่งบนเวิร์ด เอกเซล และเอาท์ลุคอยู่แล้วและอยากร่างเอกสารเร็วขึ้น
  • ทีมที่ประชุมในทีมส์แล้วต้องการสรุปที่ดึงจากไฟล์ในเทแนนท์
  • คนที่แยกได้ว่าแชทส่วนตัวกับพื้นที่งานองค์กรไม่ใช่ที่เดียวกัน

ข้อจำกัดที่ต้องยึด

  • Copilot ใน 365 เป็นส่วนเสริมคิดเงินแยก อย่าสัญญาลูกค้าว่ามีในทุกที่นั่ง
  • ผลภาษาไทยต้องตรวจโทนและข้อเท็จจริงก่อนส่งออก
  • ห้ามวางข้อมูลส่วนบุคคลของลูกค้าลงชั้นผู้บริโภค

ทีมเอสเอ็มอีบน Microsoft 365 ใช้ยังไงให้ไม่รั่วบรีฟ

ออฟฟิศหลายแห่งในลาว ไทย และเวียดนามจ่ายชุด Microsoft 365 อยู่แล้วเพราะอีเมลและไฟล์แชร์ คนจึงคิดว่า Copilot คือปุ่มฟรีที่โผล่มาให้กด ชั้นที่ควรเปิดก่อนคือถามผู้ดูแลว่าเทแนนท์มี Copilot ใน 365 หรือยัง ถ้ายังมีแค่แชทบนเว็บ ให้ใช้ร่างข้อความทั่วไปที่ไม่มีชื่อลูกค้า ห้ามวางบรีฟโรงแรม รายได้คลินิก หรือรายชื่อผู้เข้าอบรมลงกล่องผู้บริโภค

เมื่อเทแนนท์มี Copilot ใน 365 จริง การสรุปเธรดเอาท์ลุคหรือการร่างสไลด์จากโฟลเดอร์แชร์ช่วยลดเวลาเตรียมประชุมกับลูกค้าต่างจังหวัดได้ Microsoft ระบุว่ากราวด์ผ่าน Graph อยู่ในขอบเขตสิทธิ์ ทีมยังต้องตั้งโฟลเดอร์ให้บรีฟอ่อนไหวไม่อยู่ในไลบรารีที่ทุกคนค้นได้ การมีกราวด์ไม่เท่ากับการมีนโยบายจัดเก็บ

งานเขียนภาษาไทยบนเวิร์ดใช้ Copilot ได้ตอนอยากได้โครงจดหมายหรือโครงเคส แต่ประโยคที่โมเดลเลือกมักเป็นภาษาราชการแข็งหรือภาษาโฆษณาเกิน ให้นักเขียนท้องถิ่นปรับระดับภาษาให้ตรงกับไลน์ที่ลูกค้าคุยกับร้าน งานรัฐหรืองานโรงพยาบาลมีคำที่ห้ามทาย อย่าให้โมเดลเติมตัวเลขที่ไม่มีในไฟล์ต้นทาง

เอกเซลช่วยจัดคอลัมน์และอธิบายสูตรได้สะดวกเมื่อทีมเล็กไม่มีนักวิเคราะห์ประจำ ตรวจผลรวมด้วยมือทุกครั้งก่อนเสนอลูกค้า ตัวเลขแคมเปญที่ผิดหลักเดียวทำให้ใบเสนอเสียความน่าเชื่อถือทั้งฉบับ เพาเวอร์พอยต์เช่นกัน ใช้ย่อหัวข้อจากเอกสารที่ตรวจแล้ว อย่าให้สร้างสไลด์จากประโยคคลุมเครือในแชท

บนวินโดวส์ Copilot ช่วยเรียกงานบนเครื่องได้ตามที่ Microsoft อธิบายในรุ่นนั้น แต่เครื่องที่ใช้ร่วมกันในออฟฟิศเอเจนซีอาจมีไฟล์ลูกค้าหลายราย อย่าเปิดประวัติแชทบนเครื่องส่วนกลางโดยไม่ล็อกบัญชี ชั้นผู้บริโภคบนเว็บยิ่งไม่ควรเป็นที่เก็บรหัสผ่านหรือสแกนบัตร

ช่องทางขายในภูมิภาคนี้จบที่ไลน์และวอทส์แอปป์มากกว่าเอาท์ลุค ใช้ Copilot ร่างข้อความแล้วคัดลอกไปแอปแชทได้ แต่ตรวจชื่อเล่นและคำลงท้ายให้เป็นคน ข้อความที่ฟังเหมือนจดหมายบริษัทใหญ่ทำให้ร้านท้องถิ่นดูแปลก เก็บแม่แบบที่คนแก้แล้วในโฟลเดอร์ทีม อย่าเริ่มจากศูนย์ทุกครั้งในแชทที่ไม่มีประวัติแบรนด์

ถ้าลูกค้าถามเรื่องราคา Copilot บอกตรง ๆ ว่าชั้นผู้บริโภคกับชั้น 365 คนละใบ และตัวเลขอยู่บนหน้า Microsoft ของสัญญาคุณ เราไม่ใส่จำนวนในรีวิวนี้ ห้ามรับปากว่าจะติด Copilot ให้ทั้งออฟฟิศโดยยังไม่เปิดศูนย์จัดการของเทแนนท์
